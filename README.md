# NovaChat — исходники мессенджера Android + сервер

В комплекте: Android WebView-проект, интерфейс в тёмной теме и Node.js API с Socket.IO для сообщений в реальном времени, регистрацией/входом, профилями, поиском пользователей, личными чатами, группами и каналами.

## Важно: онлайн-сервер не размещён автоматически
Для настоящей переписки нужен постоянно работающий сервер с публичным HTTPS-доменом. Этот архив содержит серверный код, но не включает оплаченный/размещённый хостинг. До публикации серверного URL и настройки адреса в приложении реальные пользователи не смогут обмениваться сообщениями через интернет.

## Запуск сервера
1. Установить Node.js 20+.
2. В каталоге `server` выполнить `npm install`.
3. Задать случайный секрет не менее 32 символов в переменной окружения `JWT_SECRET`.
4. Запустить `npm start` (порт по умолчанию 3000).
5. Разместить за HTTPS reverse proxy. Постоянный диск требуется для `data.json`. Не открывать API в публичный интернет без HTTPS и надёжного секрета.
6. Открыть приложение и вписать URL сервера, например `https://chat.example.com`.

## Сборка APK
Открыть папку `android` в Android Studio, установить Android SDK 35 и выполнить Build > Build APK(s). Результат обычно находится в `android/app/build/outputs/apk/debug/app-debug.apk`.

## Примечания
- Интерфейс загружает Socket.IO-клиент с CDN; устройство должно иметь интернет.
- Это стартовый проект, не полноценная замена Telegram: нет сквозного шифрования, звонков, push-уведомлений, отправки файлов и восстановления пароля. Не использовать для секретной переписки.
- Для реального публичного запуска добавьте лимиты запросов, проверку членства/прав канала, модерацию, резервное копирование и безопасную базу данных вместо JSON-файла.
